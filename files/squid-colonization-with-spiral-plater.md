# Determination of squid colonization levels using spiral plating

This note provides instructions for using the Neutec EddyJet and SphereFlash for the determination of colonization levels. 
Colonization experiments should be performed per lab protocol as specified [here](/squid-colonization.md) with the following modifications

## Step 14.14

Orignal Protocol
> Transfer each squid in a volume of approximately 700 μl to a 1.5 ml microcentrifuge tube from Step 4.12. Move to a cardboard freezer box. Once the lid is placed on the box, do not remove it as the light cues for bacteria expulsion are not well-understood.

Instead of 700 uL, fill the tube to 1 mL. The machine calculates CFU/mL by default, but this would not be synonomous with CFU/mL if the sample somes from a 700 uL stock. 

If you do not make this modification, you will need to do ONE of the following to obtain correct counts.
- When squid are thawed for plating, top off the microtubes to 1 mL using FSIO. After plating/counting, use the CFU/mL value from the SphereFlash as reported
- If you use the 700uL samples for plating, after getting the CFU/mL value from the SphereFlash you will need to calculate how many bacteria would be in 700 uL. Take the CFU/mL reported and multiply is by 0.7.
