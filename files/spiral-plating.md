## Equipment Specifications
* The EddyJet spiral plater in lab is a Neutec Group EddyJet 2W automatic plater for spiral spreading (115V/220V)
* The SphereFlash in the lab is a Neutec Group IUL SphereFlash (1.0.1.16) automatic colony counter. It uses SphereFlash Colonies PRO Software. 
  * The Camera SN is 9420172 

Sample methods statment for publication:  
> Bacteria were spread using the EddyJet automatic plater (Neutec Group) using the _ setting. Plates were grown for X hours at X C then imaged with the SphereFlsh automatic counter (Neutec Group). Images were processed with the SphereFlash Colonies Pro Software to obtain CFU/mL for each sample.
